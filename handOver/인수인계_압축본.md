# ODD Data Selection 프로젝트 인수인계 (요약본)

> 상세 배경·트러블슈팅은 [인수인계_상세본.md](./인수인계_상세본.md) 참고. 여기는 핵심만 압축.

## 한 줄 요약

ODD 태깅 데이터(AAA1/LSD)와 Motional 시나리오 데이터를 Kafka로 실시간 수신 → 1fps 다운샘플링 + 시간 매칭 후 Elasticsearch에 통합 색인 → **태그 클릭으로 검색하고, 그 결과를 CSV 추출·검수 UI(Accept/Reject)로 실제 실행까지** 하는 웹 시스템. 여기에 더해 **자연어 문장으로 검색하는 AI 기능도 프로토타입으로 추가 완성**되어 있음.

## 목표 & 스코프

- 최초엔 "자연어 쿼리 → 데이터 경로 반환"으로 시작 → "SaaS급 아키텍처(정책기반+Kafka+IP보호)"로 요구 확장 → 인턴 잔여기간(3주) 고려해 **"단순화된 파이프라인(파일/태그 검색 수준)"으로 스코프 현실화** (4번의 피드백 사이클 거침, 8/5부터 이 기준으로 구현 착수)
- 이번에 완성한 것: 태그 기반 검색 + 실행(CSV 추출, 검수 UI로 최종 Accept/Reject)까지
- 자연어 쿼리(LLM 기반)는 원래 스코프는 아니었으나, 인턴 기간 중 추가로 프로토타입까지 진행하여 실제 검색 UI에 통합 완료 (아래 별도 섹션 참조)

## 아키텍처 한 장 요약

```
Qumulo(원본) → Kafka(dev.shared.odd-tagging.input)
  → kafka_consumer.py(상시구동) → unified_pipeline.py 로직 재사용
    (10fps→1fps 다운샘플링, Motional ±0.5초 매칭, Bulk 색인)
  → Elasticsearch(odd-frames-v2, 현재 976건)
  → 검색 UI(index.html: 체크박스 필터 + AI 자연어 검색) / 검수 UI(review.html) ← server.py
                                                              ↑
                                              vLLM(시은 GPU 서버, AI 자연어 검색 전용)
```

## 처음 접속할 때 필요한 세팅

| 포트            | 용도                    | 여는 방법                                                                  | 필수 여부              |
| --------------- | ----------------------- | -------------------------------------------------------------------------- | ---------------------- |
| `8080`          | 검색/검수 UI            | VSCode PORTS 탭 (strad35 세션)                                             | 필수                   |
| `9200` / `5601` | ES / Kibana             | VSCode PORTS 탭                                                            | 필요할 때만            |
| `8001`          | vLLM (AI 자연어 검색용) | **터미널에서 직접**: `ssh -L 8001:127.0.0.1:8001 stradvision@10.50.10.181` | AI 자연어 검색 쓸 때만 |

- `8001`은 strad35가 아니라 **시은 개인 GPU 서버**로 가는 별도 터널이라 VSCode 자동 포워딩 대상이 아님. 이 터미널 창을 계속 열어둬야 하고(VSCode 종료 시 같이 끊길 수 있음), 태그 기반 검색은 이거 없이도 완전히 정상 작동함.
- 상세 순서(서비스 상태 확인 → UI 접속 → vLLM 터널 → 데이터 검증 → 저장소/자격증명)는 [인수인계_상세본.md](./인수인계_상세본.md) 0-1 섹션 참고.
- ⚠️ 시은도 인턴이라 Motional/vLLM 담당이 다른(미정) 사람에게 넘어갈 예정 — 연락 전
  인프라 담당자에게 현재 담당자 확인 필요. 신규 환경 이전 방법은
  [인수인계_자격증명관리.md](./인수인계_자격증명관리.md) 5번 참고.

## 자연어 쿼리 (LLM 기반) — 프로토타입 완료

- vLLM(Qwen3-14B-FP8, 시은 개인 GPU 서버, SSH 터널로 접속) + 커스텀 프롬프트로 자연어 → 구조화 쿼리(중첩 AND/OR) 변환기 구현, v1~v20까지 반복 개선
- 체크박스 필터와 완전히 분리된 별도 검색 경로로 index.html에 통합 (`/api/nlquery` 엔드포인트)
- AAA1 + LSD + Motional 전체 대상, 영어 입력도 지원
- 상세 개발 기록/버전별 정확도/일반화 평가는 Confluence [Query Parsing] 자연어 → 구조화 쿼리 변환 개발 기록 문서 참조
- **알려진 한계**:
  - held-out 성격 표적문항(hallucination 재현 10 + auto-flag 표적 7 = 17문항) 기준 76~82% — 동의어 표현(예: "근처에" vs "둘러싸인") 일반화는 모델을 14B로 올린 뒤 부분 개선 확인됨, blind 검증은 아직 필요 (상세본 9-4 참조)
  - auto 플래그(night 동의어 인식 부족, B-2) 오분류가 표적 문항의 약 43%(3/7)에서 여전히 발생 — 검색 결과 자체(필드 값)엔 영향 없고 UI 배지 표시만 부정확한 사소한 이슈
  - vLLM이 시은 개인 서버에서 임시 실행 중이라 예고 없이 중단될 수 있음 (위 세팅 표 참조)
  - `low_streetlight_road` 필드 하나에서 auto 플래그(UI 배지) 표시만 미세하게 부정확 (검색 결과 자체엔 영향 없음, 사소한 잔여 이슈)

## 자주 겪는 이슈 Top 6

| 증상                                 | 해결                                                                                                                                                    |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| systemd 서비스 로그가 안 보임        | `ExecStart`에 `-u` 옵션 추가                                                                                                                            |
| Kafka Python에서 `AWS_MSK_IAM` 에러  | `OAUTHBEARER` + `oauth_cb`로 구현 (Java 클라이언트 이름과 다름)                                                                                         |
| 이미지 API에서 정상 이미지도 차단됨  | 프레임 파일이 심볼릭 링크인 경우 `IMAGE_ALLOWED_ROOTS`에 링크 대상 경로 추가                                                                            |
| 신규 데이터 유입 후 검증 방법        | ① 건수 확인(`_count`) ② `audit_pipeline.py` 전수 감사 ③ UI 샘플 확인 — 3단계, 약 2분                                                                    |
| AI 자연어 검색이 "Connection error" | vLLM 꺼져있거나 SSH 터널(8001) 끊김 → `lsof -i :8001`로 확인, 필요시 담당자에게 재기동 요청(⚠️ 위 세팅 경고 참고). 반복되면 [인수인계_자격증명관리.md](./인수인계_자격증명관리.md) 5번으로 환경 이전 검토 |
| LLM이 특정 필드에서만 규칙을 안 지킴 | 확정적인 규칙(예: LSD=야간 전용)은 프롬프트로 계속 다듬기보다 후처리 코드로 강제 보장하는 게 안정적                                                     |
