| 증상                                                                        | 원인                                                                                                                                                              | 해결                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sudoers file` 에러 (권한 부여 직후)                                        | 기존 SSH 세션이 권한 반영을 즉시 인식 못함                                                                                                                        | 완전 로그아웃 후 재접속                                                                                                                                                                                                                                    |
| `docker-compose-plugin` apt 설치 불가                                       | Docker가 공식 저장소 경유로 설치된 게 아님                                                                                                                        | GitHub 릴리즈에서 바이너리 직접 다운로드(SHA256 체크섬 검증) 후 `~/.docker/cli-plugins/`에 개인 설치 — 공유 서버에서는 시스템 전역 변경보다 영향 범위 최소화 방식 우선                                                                                     |
| ES 컨테이너 최초 기동 실패 (`AccessDeniedException: node.lock`)             | 정확한 원인 미확정 (볼륨 마운트 타이밍 추정)                                                                                                                      | `docker compose down` → `up` 재시도로 대부분 해결. 재현 시 `chown -R 1000:1000 <경로>`부터 점검                                                                                                                                                            |
| systemd 서비스는 `active`인데 `journalctl`에 로그 안 보임                   | Python stdout이 파이프 환경에서 버퍼링됨                                                                                                                          | `ExecStart`에 `-u`(unbuffered) 옵션 추가                                                                                                                                                                                                                   |
| Docker network 간 컨테이너 통신 안 됨 (Kibana ↔ ES)                         | 컨테이너가 필요한 네트워크에 미가입                                                                                                                               | `docker network connect elk_default odd-kibana` 로 확인·연결                                                                                                                                                                                               |
| Kafka Python 클라이언트에서 `AWS_MSK_IAM` 미지원 에러                       | 그 이름은 Java 클라이언트 전용                                                                                                                                    | `sasl.mechanisms: OAUTHBEARER` + `oauth_cb`로 구현                                                                                                                                                                                                         |
| Kafka 인증 타임아웃                                                         | (a) `.env` 값이 실제로 비어있거나 (b) 라이브러리 버전마다 `generate_auth_token()` 파라미터 시그니처가 다름                                                        | 키 길이(`len()`)로 값 존재 확인, `help()`로 실제 함수 시그니처 확인 후 맞춰서 호출                                                                                                                                                                         |
| 이미지 API 경로 제한 적용 후 정상 이미지까지 차단됨                         | 프레임 파일이 심볼릭 링크였고, `realpath()`가 링크 대상 경로로 해석                                                                                               | `IMAGE_ALLOWED_ROOTS`에 링크 대상 경로도 추가. `ls -la`로 링크 여부 먼저 확인하는 습관                                                                                                                                                                     |
| `.env` 값 변경했는데 서버에 반영 안 됨                                      | 모듈 최상단 코드가 `.env` 로드보다 먼저 실행되어 전역 변수 계산                                                                                                   | `.env` 로드 이후에 값을 (재)계산하거나, `load_config()` 함수로 묶어서 매번 읽기                                                                                                                                                                            |
| AI 자연어 검색이 "Connection error"로 실패                                  | vLLM이 꺼져있거나, SSH 터널(`ssh -L 8001:127.0.0.1:8001 ...`)이 끊긴 상태                                                                                         | `lsof -i :8001`로 vLLM 프로세스 생사 확인(시은 서버에서) → 꺼져있으면 Motional/vLLM 담당자에게 재기동 요청 (⚠️ 문서 작성 시점 담당자는 시은이나 인수인계 예정 — [인수인계_상세본.md](../handOver/인수인계_상세본.md) 0-1 섹션 경고 참고, 먼저 인프라 담당자에게 현재 담당자 확인), 터널만 끊긴 거면 터널 재연결 후 `sudo systemctl restart odd-search-ui`. 이런 일이 반복된다면 임시방편 대신 [인수인계_자격증명관리.md](../handOver/인수인계_자격증명관리.md) 5번의 신규 환경 구축을 고려 |
